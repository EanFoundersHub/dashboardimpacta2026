# IMPACTA 2026

Startup Report interactivo de Ean Impacta: panorama respaldado, Insights auditables, filtros positivos, directorio y expedientes editoriales.

Sitio público: <https://eanfoundershub.github.io/dashboardimpacta2026/>

La publicación se realiza automáticamente mediante GitHub Actions y GitHub Pages desde la rama `main`.

La capa pública no incluye datos personales ni montos de inversión. Los Insights se generan desde las fuentes institucionales con un script reproducible en `tools/build-insights-data.py`.
